# Toán Vui Lớp 1 🦊🍎

Website học Toán tương tác dành cho bé lớp 1.

## Chơi ngay

Mở file `index.html` hoặc xem qua GitHub Pages (sau khi bật).

**Link repo:** https://github.com/PuHg26/toan-vui-lop-1

## Cách bật GitHub Pages để chơi online
1. Vào repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **(root)**
4. Save
5. Đợi 1-2 phút rồi mở: `https://puhg26.github.io/toan-vui-lop-1/`

## Có gì trong web?
- Đếm số (quả táo, cam, chuối...)
- Cộng trừ trực quan
- Nhận biết hình học
- Xem đồng hồ
- Có sao thưởng + âm thanh khen

Làm bằng HTML + CSS + JS thuần, chạy được trên mọi trình duyệt, kể cả điện thoại.
